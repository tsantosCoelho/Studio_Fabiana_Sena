# 💅 Beauty Services Website

Responsive website developed for a beauty professional specializing in manicure and eyelash extension services (cluster lashes).

## ✨ Overview

The project aims to present services in a modern way and make client communication easier.

## 🚀 Features

- Responsive design (mobile, tablet, desktop)
- Work portfolio gallery
- Contact section
- WhatsApp integration for quick booking

## 🎯 Goal

To improve client booking experience and strengthen the professional’s online presence.

## 🛠️ Tech Stack

HTML • CSS • JavaScript

# 💅 Site de Serviços de Beleza

Desenvolvimento de um site responsivo para uma profissional da área de beleza especializada em manicure e extensão de cílios em tufos.

## ✨ Visão geral

O projeto tem como objetivo apresentar os serviços de forma moderna e facilitar o contato com clientes.

## 🚀 Funcionalidades

- Design responsivo (mobile, tablet e desktop)
- Portfólio de trabalhos
- Seção de contato
- Integração com WhatsApp para agendamento rápido

## 🎯 Objetivo

Facilitar o agendamento de serviços e melhorar a presença digital da profissional.

## 🛠️ Tecnologias

HTML • CSS • JavaScript
